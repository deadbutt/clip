# HY-MT2 字幕上下文试验与默认配置

日期：2026-09-20。目的：在现有本地翻译速度基础上，改善短字幕的语境理解，不重跑转录。

## 最终选择

默认前后各 2 段**原文字幕**，保持一条请求只翻译当前一段。参考文字每侧最多 300 字符，合计 600 字符；距目标段超过 12 秒的邻段不带入。沿用原文顺序、说话人标签、保护词、temperature=0、16 个请求线程、8 个服务槽和每条最多 512 个输出 token。不传先前译文，避免错误沿后续字幕传播。

模型仍使用 Hy-MT2-1.8B-Q4_K_M，llama.cpp b11026-b49650adb；总 KV 上下文 16384、8 槽，每槽 2048 token，不扩大显存配置。`batch_size=2048` 和 `ubatch_size=512` 是底层计算 token 批量，不是字幕段数。

使用官方背景信息提示的思路，并明确当前任务是口语字幕、只翻译目标文本。将公共保护词前缀放在上下文前，保留共享前缀缓存收益。移除了探索版本中放在翻译指令前的“Source Text, speaker”标签，以减少模型复述参考字幕的情况。

通过 `--translator-hy-context-window 0` 可恢复无上下文；支持 0、1、2、3，默认 2，需要重启 Web 服务。Python 调用 `translate_segments(..., context_window=0)` 可以按次覆盖。

## 素材与方法

- 使用用户指定 `runs/8674c9a0638f/segments.source.json` 的快照，共 482 段；原有跳过规则保留 21 段原文，实际翻译 461 段。源视频约 22.75 分钟。
- 未再次转录，也未覆盖任务原有字幕、词时间戳或源稿。快照、逐句结果、实验脚本和新版双语 SRT 位于 `runs/8674c9a0638f/hy-context-check/`。
- 先固定选择 111 段：不完整句、游戏术语、捏脸/加属性点对话，以及 seed=1729 的随机样例。比较 0/1/2/3 段窗口，以及原提示、简化英语提示、中文提示、移除目标标签和口语字幕提示。
- 中文提示在样例中把 Neuro 改成 Neuro-sama；大窗口也没有稳定改善，且出现参考内容泄漏，因此没有作为默认。
- 发现 llama.cpp 默认的 RAM 提示缓存会让第二轮同一请求接近整段命中。探索版本每侧 2 段曾出现 14.84→7.39 秒；这不是算法提速，不能拿缓存命中后的成绩代表首次处理。
- 最终验收启动独立的本地 8091 服务，仅额外设 `--cache-ram 0` 消除跨请求的完整历史缓存；保留正常 KV 前缀复用。运行中的 8090 服务不停止、不改配置。测试顺序 0→1→2→2→1→0，每组先用末尾 8 段预热，模型加载和预热不计入翻译时间。
- 最终计时调用正式 `HyMtTranslator.translate_segments`，包含跳过规则、并发、上下文组装和异常检测/重译路径；未使用 AI 服务评分或云端翻译。
- 中间完整对照中 GPU 繁忙样本 SM 中位数为 780MHz，显存约 4590MiB（包含原有空闲服务与诊断服务）；记录了 GPU 采样。最终验收结果是本次本机配置的成绩，不是所有电源状态下的速度保证。

## 语境效果与局限

以下来自正式验收结果。没有人工标注的完整金标准，未计算准确率或声称所有句子变好。

| 原文/场景 | 无上下文 | 各 2 段 |
| --- | --- | --- |
| 某处对话中的 `No.`（快照索引 163） | 编号。 | 不。 |
| `Alright, maybe a little bit of reflexes.`，正在讨论属性点 | 好吧，也许有点反应能力。 | 好吧，或许可以加入一些反应能力。 |
| `Imagine how much cooler we could look by focusing on technical ability.` | 想象一下，如果我们专注于技术能力，会显得多么更出色。 | 想象一下，如果我们专注于技术能力，我们会看起来多么酷。 |
| `...We don't have enough ability points today, I don't think.` | 今天我们没有足够的能力值。 | 我觉得今天我们的能力点数不够。 |
| `...one less point in cool and one more in technical ability.` | 也许“酷”这个方面少一个分数，而“技术能力”方面多一个分数。 | 也许“酷炫度”少一点，“技术能力”多一点。 |

仍有明显局限：

- 其他 `No.` 仍可能译为“编号”；上下文没有普遍解决这个问题。
- `cyberware` 没有稳定采用游戏术语“义体”，`quickhacks` 也可能仍译成“快速技巧”。需要领域术语映射或校对，保护词只是保留原文。
- `Maybe we don't do reflexes.` 仍未正确理解为“也许不加反应属性”。
- 某些轮次把 `gang` 或 `rizzz` 留作英文，存在退步，不能声称逐句不降质。
- temperature=0 下，动态并发批次仍出现少量措辞差异；不能当作逐位确定性保证。

## 异常防护与验证

探索版曾把前后字幕一并译出，因此正式路径增加检测：背景说明语、提示标签、说话人标签、空输出或异常膨胀时，仅对当前段重新执行原无上下文翻译，并保留保护词。单段重译仍明显异常时保留原文，由既有失败计数及日志报告。此检测不能识别所有无标签的串句或语义误译。

上下文不改变原字幕 ID、数量和时间边界，也不把相邻段合成新的字幕。输入快照与原源稿哈希保持一致。
